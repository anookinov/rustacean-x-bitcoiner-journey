Setting up Bitcoin Node and Self-Sovereignty Software

This section explains how to install and configure Bitcoin Core and other self-sovereignty applications on your Start9 OS via the web interface. The goal is to build a complete sovereign stack for financial independence and privacy.

Pre-requisites

Before starting, ensure you have completed all hardware setup and network configuration steps as outlined in the previous section.

Preparations

  • Hardware setup and Start9 OS installation completed
  • Network configuration and internet connectivity verified
  • Access to Start9 web interface (https://xxx-yyy.local or via IP address)
  • Start9 OS initial setup wizard completed
  • Proxmox VE host secured if using virtualization (optional)

Hardware

  • MINISFORUM X1-255 Mini PC (or similar x86_64 hardware, with RAM and SSD installed)
  • AT&T BGW320 router (with available LAN ports)
  • Monitor and keyboard (for initial setup and troubleshooting)
  • MacBook Air M1 or other laptop/desktop (for remote access and management)

Software

  • Start9 OS installed and running (latest stable release)
  • Web browser (Safari, Chrome, Firefox, etc.)
  • SSH client (optional, for advanced troubleshooting)

References

  • Start9 Documentation
  • Bitcoin Core Documentation
  • Lightning Network Resources
  • Start9 OS Downloads
  • Start9 Community Forums

Essential Stack (Recommended First)

  1. Bitcoin Core - Foundation of everything
  2. Mempool Explorer - Visualize blockchain data
  3. Electrum Server - Connect your wallets

Total time: ~30 minutes setup + sync time

Privacy & Communication Stack (Anytime)

  2. Privacy Tools - Enhanced sovereignty

  1. Lightning Network - Instant payments
  2. BTCPay Server - Accept payments

Total time: ~30 minutes setup

Important Considerations

Storage Requirements

  • Bitcoin Core: ~600GB (and growing ~50GB/year)
  • Mempool Explorer: ~5-10GB
  • Electrum Server: ~80-100GB index
  • Nostr Relay: ~1-5GB (depends on usage)
  • Privacy Tools (Tor Relay/Bridge, Syncthing, Vaultwarden, Nextcloud, Bitwarden): ~1-10GB each
  • Lightning Network: ~1-5GB (depends on channels)
  • BTCPay Server: ~2-5GB

Recommended minimum: 1TB SSD for Bitcoin infrastructure

Initial Blockchain Download (IBD)

Bitcoin Core must download and verify the entire blockchain history:

  • Time required: 1-7 days (depending on hardware and internet speed)
  • During IBD: Your node validates every transaction since 2009
  • Be patient: This is a one-time process that ensures full sovereignty
  • Network usage: ~600GB download (one-time)

Tip: Most services (including Mempool Explorer, Electrum Server, Lightning Network, BTCPay Server, and privacy apps) require Bitcoin Core to be fully synchronized before they can function.

Resource Usage

  • CPU: Bitcoin Core uses moderate CPU during IBD, minimal after sync. Mempool Explorer, Electrum Server, Nostr Relay, and privacy tools use minimal CPU after initial setup.
  • RAM: Start9 OS manages resources efficiently; 32GB recommended for full stack including privacy and communication apps.
  • Network: Bitcoin Core uses ~200GB/month upload bandwidth after sync. Nostr Relay and privacy tools may use additional bandwidth depending on usage.
  • Storage: Plan for blockchain growth (~50GB/year) and additional privacy/communication app data.

Port Forwarding (Optional but Recommended)

For optimal Bitcoin network participation:

  • Bitcoin Core: Port 8333 (TCP)
  • Lightning Network: Port 9735 (TCP)
  • Nostr Relay: Port 4848 (TCP, optional, for public relay access)

Forwarding these ports allows your node and apps to accept inbound connections, strengthening the Bitcoin and Nostr networks.

Backup Recommendations

After installing services:

  • Backup seed phrases: Write down and store securely offline
  • Backup Lightning channels: Use Start9’s backup feature
  • Backup Nostr relay data and privacy tool configurations: Use built-in backup/export features
  • Backup Start9 configuration: Create system snapshots
  • Store backups offsite: Protect against hardware failure
