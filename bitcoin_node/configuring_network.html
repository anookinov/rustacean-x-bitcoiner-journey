Configuring Network Settings (Start9 OS)

This guide provides step-by-step instructions to configure the network connection in Start9 OS to enable internet access and confirm your node has full gigabit connectivity for optimal blockchain synchronization. You’ll learn how to set up your network, verify DHCP IP assignment, confirm gigabit connection speed, run speed tests, and troubleshoot any issues to ensure your node is ready for reliable Bitcoin operation.

In this guide, you will:

  • Set up network access for Start9 OS (native or VM)
  • Access the web interface and find your device
  • Configure static IP, DNS, and advanced options
  • Verify your node is using a wired gigabit connection and check network speed
  • Troubleshoot common network issues

Pre-requisites

Preparation

  • Complete one of the following installation methods:
    • Booting Start9 OS directly on Minisforum device
    • Virtualized Start9 OS Setup Guide (recommended for hardware compatibility and used in this guide)
    • Alternative installation on Ubuntu/Debian
  • Basic familiarity with web interfaces or Proxmox console
  • Ensure you have access to your AT&T BGW320 router and its admin interface.
  • Gather your Start9 node credentials and device information (IP, device ID).
  • Confirm you have a laptop/desktop on the same network as your Start9 node.
  • Use a wired Ethernet connection (Cat 5e or higher) for your node and verify gigabit connectivity for optimal performance.

Hardware

  • MINISFORUM X1-255 Mini PC (or similar x86_64 hardware)
  • Ethernet connection to AT&T BGW320 router (Cat 5e or higher cable required for gigabit speeds)
  • Monitor and keyboard (native boot) or Proxmox web console (VM)
  • AT&T BGW320 router with DHCP enabled (default)
  • Laptop/desktop on the same network (for speed test comparison)

Software

  • Start9 OS installed (native or VM)
  • Web browser (Safari, Chrome, Firefox, etc.)
  • Access to Proxmox web interface (if using VM)
  • SSH client (for command-line speed checks)
  • speedtest-cli (for bandwidth testing, optional but recommended)

References

  • Start9 OS Documentation – Networking
  • AT&T BGW320 Router Manual

Step-by-Step Instructions

Step 1: Access Start9 OS Web Interface

You can access the Start9 OS web interface after installation, whether running as a Proxmox VM or natively on Minisforum hardware.

For Proxmox VM Installation

If you installed Start9 OS as a Proxmox VM, you have two ways to access the web interface:

Option 1: Access via Start9 Hostname (.local)

  1. From your MacBook (or any device on the same network), open a web browser.
  2. Type https://xxx-yyy.local (replace with your device name) directly into the address bar and press Enter.
  3. The browser will connect to your Start9 OS instance on the local network using mDNS/Bonjour.
  4. If the .local address does not work, try your device’s local IP address (e.g., https://192.168.1.101).
  5. Log in with the master password you set during installation.

🔎 Device Name Lookup: In the Start9 web interface, go to System → About → Web Addresses → LAN. The .local address uses your device name (e.g., xxx-yyy.local). For Proxmox VE, use the VM’s hostname as shown in your router’s device list or network settings.

Option 2: Access via Private IP Address

  1. In Proxmox web interface, select your Start9 VM (start9-bitcoin-node)
  2. Click Summary tab to view VM details
  3. Note the IP Address (e.g., 192.168.1.101 if you configured static IP)
    • Or check the Proxmox console for the IP address displayed on the Start9 login screen
  4. From your MacBook (or any device on the same network), open a web browser
  5. Navigate to https://192.168.1.101 (replace with your actual IP address)
  6. Accept the self-signed certificate warning:
    • Safari: Click “Show Details” → “visit this website”
    • Chrome: Type thisisunsafe (no spaces) on the warning page
    • Firefox: Click “Advanced” → “Accept the Risk and Continue”
  7. Log in with the master password you set during installation

Network Configuration in Proxmox VM:

  • The VM automatically obtains an IP via DHCP from your router
  • The Proxmox bridge (vmbr0) connects the VM to your LAN
  • No additional network configuration needed - Start9 OS handles this automatically
  • The VM appears as a regular device on your network (192.168.1.x range)

For Native Boot Installation

If you’re running Start9 OS directly on the Minisforum hardware (native boot), simply follow the on-screen setup wizard after first boot. Select a wired Ethernet connection for best reliability and performance, and complete the guided steps to finish network setup and access the web interface.

Step 2: Verify Automatic Configuration

📡 DHCP: The BGW320 router handles IP address assignment automatically via DHCP, so no manual network configuration is typically needed.

The BGW320 router automatically assigns network settings via DHCP:

  1. Start9 OS will attempt to obtain an IP address automatically
  2. Wait a few seconds for DHCP negotiation to complete
  3. The system will display the assigned IP address (typically in the 192.168.1.x range)
  4. Confirm the connection status shows as “Connected” or “Active”

Where to find your Start9 OS IP address:

  • In the Start9 web interface, go to System → About and look for the ens18 (IPv4) entry. This shows your device’s current IP address on the network.

Example IP assignment:

  • IP Address: 192.168.1.101
  • Subnet Mask: 255.255.255.0
  • Gateway: 192.168.1.254 (BGW320 router)
  • DNS Servers: Automatically provided by router

🧩 IP Assignment Help: If no IP address is assigned:

  • Verify the Ethernet cable is securely connected at both ends
  • Check that the connection LEDs are lit on both Mini PC and router
  • Ensure the BGW320 router has available DHCP addresses
  • Try unplugging and replugging the Ethernet cable

Step 3: Confirm Wired Gigabit Connection

  1. Ensure your Start9 node is connected via wired Ethernet (not Wi-Fi)
  2. Use a Cat 5e or higher Ethernet cable
  3. Plug into a gigabit port on the BGW320 router
  4. Check the router’s device list for your node (should show 1000 Mbps or 1 Gbps)
  5. If using a VM, check the Proxmox summary for the VM’s network interface

📊 Network Speed Insights:

  • Initial blockchain sync for Bitcoin Core can take days. Gigabit speed reduces this from weeks (at 100 Mbps) to days (at 1 Gbps).
  • 900–950 Mbps is excellent; protocol overhead and network conditions mean you’ll rarely see exactly 1000 Mbps.
  • Upload speed is important for serving blocks; fiber connections (like AT&T Fiber 1 GIG) provide symmetric speeds.
  • Consistent connection is more important than absolute max speed. A stable 500 Mbps is better than a flaky 1000 Mbps.
  • Streaming or large downloads on your network may impact speed test results. Run tests when the network is idle for best results.

Step 4: Check Speed via Router Admin Interface

  1. Open your AT&T BGW320 router admin page (192.168.1.254)
  2. Go to Device → Status
  3. Find your Start9 device in the list (labeled “start” or “start9”)
  4. Click More Info next to “Home Network Devices”
  5. Select Device → Device List to view connection details
  6. Check the connection details (type, speed, IP address, etc.)

🌐 Network Verification & Bandwidth:

  • The AT&T router device list is the most reliable way to verify your Start9 node’s network connection.
  • Check if your ISP has data caps. Running a Bitcoin node uses significant bandwidth (20-50 GB/month for pruned, 200+ GB/month for full archival).

Expected results:

  • Type: Ethernet (wired connection)
  • Speed: 1000 Mbps or 1 Gbps (gigabit connection)
  • IP Address: Should match your Start9 node (e.g., 192.168.1.101)
  • Status: Connected

🔄 Ongoing Monitoring: After setup, your node will maintain connections to other nodes. Gigabit speed ensures you can serve blocks and relay transactions efficiently.

Alternative Methods for Speed Verification

If you want to check your network speed using other methods, here are some high-level options:

  • Start9 Web Interface: View network status and interface details in the dashboard.
  • Command Line (SSH): Use tools like ethtool or speedtest-cli to check link speed and run bandwidth tests.
  • External Speed Test (Laptop/Desktop): Run a speed test from another device on the same network for comparison.

For most users, the router device list and Start9 dashboard provide sufficient confirmation of gigabit connectivity. Use these alternatives only if you need additional verification or troubleshooting.

🆘 Need Help? See Troubleshooting Common Speed Issues below for common issues and solutions.

Troubleshooting Common Speed Issues

✅ Optimal (900–1000 Mbps):

  • Connection is optimal for Bitcoin node operation
  • Proceed with confidence to Bitcoin Core installation
  • Your node will sync and relay efficiently

⚠️ 100 Mbps Detected:

  • Connection negotiated at Fast Ethernet instead of Gigabit
  • Check cable quality (use Cat 5e or higher)
  • Try a different LAN port on the BGW320
  • Verify Mini PC Ethernet port isn’t damaged

⚠️ Below 100 Mbps:

  • Potential cable damage or poor connection
  • Unplug and replug both ends of Ethernet cable
  • Try a different cable
  • Check for physical damage to ports

⚠️ Speeds Vary Significantly:

  • Network congestion or other devices consuming bandwidth
  • Test during off-peak hours
  • Check router for bandwidth-heavy devices
  • Consider QoS (Quality of Service) settings on router
