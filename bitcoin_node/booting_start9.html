Booting into Start9 OS

This guide provides step-by-step instructions to boot the Minisforum X1-255 Mini PC from a USB drive containing Start9 OS and install it onto the internal SSD. It covers BIOS/boot menu access, USB boot, installation, troubleshooting, and headless setup options. Follow these steps for a smooth, reliable installation and first boot.

In this guide, you will:

  • Boot the Mini PC from a prepared Start9 OS USB drive
  • Access and configure BIOS/boot menu settings (including UEFI/Legacy mode)
  • Select the correct boot device and install Start9 OS to the internal SSD
  • Remove the USB drive and boot from SSD
  • Troubleshoot common boot, display, and hardware compatibility issues
  • Set up headless access (SSH, web UI) after installation

⚡️ Hardware Compatibility Notice: Not all hardware is fully compatible with Start9 OS’s Linux kernel. If Start9 OS fails to boot directly on the Minisforum X1-255 (kernel panics, black screens, GPU incompatibility), or you experience persistent boot/display issues, check the Troubleshooting section below or see the Virtualized Start9 OS Setup (Advanced) for the recommended virtualized setup approach using Proxmox VE.

Pre-requisites

Preparation

  • Ensure your Mini PC is connected to the router and plugged into power
  • Have a monitor (HDMI or DisplayPort) and cable ready for initial installation (can be borrowed temporarily; see Headless Setup for post-install access options)
  • Prepare a keyboard (USB or wireless with USB receiver)
  • Mouse (optional, but recommended for easier navigation)

Hardware

  • MINISFORUM X1-255 Mini PC (connected to router and power)
  • AT&T BGW320 router (or other router, powered on and accessible)
  • USB drive (8GB or larger) with Start9 OS flashed (see previous step)
  • Monitor (HDMI or DisplayPort)
  • Keyboard (USB or wireless with receiver)
  • Mouse (optional)

Software

  • Start9 OS image (flashed to USB drive)
  • SSH client (optional, for headless setup)
  • Web browser (optional, for accessing Start9 web UI)

References

  • Start9 OS Documentation
  • Start9 OS GitHub Releases
  • Minisforum X1-255 Product Page
  • AT&T BGW320 Manual

Step-by-Step Instructions

Step 1: Connect Display and Input Devices

Before powering on, connect your peripherals:

  1. Connect your monitor to the Mini PC using an HDMI or DisplayPort cable

    • Locate the video output ports on the back of the Mini PC
    • Insert the cable firmly into both the Mini PC and monitor
    • Turn on the monitor and select the correct input source

  2. Connect a keyboard to one of the USB ports on the Mini PC

    • Use a USB-A or USB-C port depending on your keyboard
    • If using a wireless keyboard, insert the USB receiver

  3. (Optional) Connect a mouse for easier navigation

    • Plug into any available USB port

Step 2: Insert the Start9 OS USB Drive

Insert the prepared bootable USB drive:

  1. Locate an available USB port on the Mini PC (front or back panel)

🔌 USB Port Selection: The installation will work from either USB 2.0 or 3.0 ports, though 3.0 is faster.

  1. Insert the USB drive containing the flashed Start9 OS image

💾 USB Drive Reminder: Make sure you’re using the USB drive you prepared in the Flashing Start9 OS step, not an empty drive.

  1. Push gently until fully seated

Step 3: Power On the Mini PC

Turn on the Mini PC for the first time:

  1. Press the power button on the Mini PC (usually on the front panel)
  2. Watch the monitor for the Minisforum logo or POST screen to appear
  3. You’ll have a brief window (2-5 seconds) to enter the BIOS/boot menu

🖥️ Multiple Monitors: If you have multiple monitors, the BIOS may display on a different screen than the one showing the OS later.

Step 4: Enter the BIOS/Boot Menu

Access the boot menu to select the USB drive:

BIOS Setup Method

  1. As soon as the Minisforum logo appears, repeatedly press DEL or F2 (for me, DEL successfully enters BIOS setup)

🛠️ Keyboard Troubleshooting: If your keyboard doesn’t work in BIOS, try a different USB port or use a wired keyboard instead of wireless.

  1. This enters the BIOS Setup utility

💻 BIOS Prompt: If you miss the BIOS prompt on first boot, simply restart the Mini PC and press DEL or F2 repeatedly during startup.

  1. Use this method to change boot order and select the USB drive for installation

Common key combinations by manufacturer:

  • Minisforum: F11, F12, DEL, or F2
  • If unsure, try pressing all of these keys repeatedly during startup
  • If you miss the timing:
    • Wait for the system to finish booting (or show “No bootable device” error)
    • Press the power button to shut down
    • Wait 5 seconds and power on again
    • Be ready to press the key as soon as you see the logo

⌨️ Boot Key Tip: If F11/F12/DEL/F2 don’t work, check the Minisforum manual for your specific model’s boot key.

Step 5: Select the USB Drive as Boot Device

Choose the USB drive from the boot options:

🛡️ UEFI Requirement: Start9 OS typically requires UEFI boot mode. Ensure your BIOS is set to UEFI mode, not Legacy/CSM mode.

If using Boot Menu (F11/F12):

  1. Use arrow keys to navigate the list of boot devices
  2. Look for your USB drive, which may appear as:
    • “SanDisk” (or your USB brand name)
    • “USB HDD” or “USB Device”
    • “UEFI: SanDisk” or similar
  3. Highlight the USB drive and press Enter

If using BIOS Setup (DEL/F2):

  1. Navigate to the Boot tab using arrow keys
  2. Find Boot Option #1 or Boot Priority
  3. Change the first boot device to your USB drive

  1. Save and Exit:

    • Try pressing F10 to save and exit (confirm when prompted)
    • If F10 doesn’t work: Use the right arrow key to navigate to the Save & Exit tab at the top menu, then select Save Changes and Exit and press Enter

  2. The system will restart and boot from the USB drive

Step 6: Start9 OS Installation Begins

⚡️ Data Loss Warning: Installing Start9 OS will erase all existing data on the internal SSD. Make sure you’ve backed up any important data beforehand.

Once the USB drive boots, the Start9 OS installation will begin:

  1. You’ll see the Start9 logo and loading screen
  2. The installer will automatically detect the internal SSD
  3. Follow the on-screen prompts to install Start9 OS onto the SSD

Installation Process:

  • The installer will partition and format the internal SSD
  • Start9 OS files will be copied from the USB to the SSD
  • This typically takes 5-15 minutes depending on hardware
  • Do not power off or remove the USB drive during installation
  1. When installation completes, you’ll be prompted to remove the USB drive and restart

🗃️ USB Use: Once Start9 OS is fully installed on the Mini PC’s internal SSD, the USB drive is no longer needed and can be safely removed and reused for other purposes.

Step 7: First Boot from Internal SSD

After installation and restart:

  1. Remove the USB drive when prompted (if you haven’t already)
  2. The system will restart automatically
  3. Start9 OS will boot from the internal SSD (no USB needed)
  4. You’ll see the Start9 setup wizard on first boot

🛠️ Boot Priority Reminder: If the system tries to boot from USB again:

  • Enter BIOS/Boot Menu
  • Change boot priority to boot from the internal SSD first
  • Save and exit

If you encounter problems booting or do not see the expected display, see Troubleshooting: Boot and Display Issues.

Headless Setup (No Monitor)

If you don’t have a monitor available, you can still set up the Mini PC using headless access methods after Start9 OS is installed. The initial boot and installation still require a display (which can be borrowed temporarily). After installation, you have three options for accessing your node from your laptop:

Option 1: Access via Web UI (used in this guide)

  • Open a web browser on your laptop and go to https://xxx-yyy.local (replace with your device name; see below)
  • Alternatively, access Start9 directly via its IP address (example: https://192.168.1.101)

🔎 Device Name Lookup: In the Start9 web interface, go to System → About → Web Addresses → LAN. The .local address uses your device name (e.g., xxx-yyy.local). For Proxmox VE, use the VM’s hostname as shown in your router’s device list or network settings.

Option 2: Access via SSH (also used in this guide)

  1. Find the Mini PC’s IP address on your router’s admin page (AT&T BGW320):

    • Open browser to http://192.168.1.254
    • Log in with your admin credentials
    • Look for “Connected Devices” or “Device List”
    • Find “start” or “Minisforum” device and note its IP address

  2. Enable SSH on Start9 (if not already enabled):

    • Access Start9 web UI from your MacBook: https://xxx-yyy.local (replace with your device name)
    • Alternatively, access Start9 directly via its IP address: https://192.168.1.101
    • Navigate to System > SSH
    • Enable SSH access and add your SSH key

  3. Connect from your MacBook:

    ssh start9@192.168.1.101
# Or, using the .local address (replace xxx-yyy with your device name):
ssh start9@xxx-yyy.local

Option 3: Direct Ethernet Connection (advanced)

You can connect your MacBook directly to the Mini PC via Ethernet for initial configuration:

  1. Connect an Ethernet cable directly between MacBook and Mini PC
  2. On your MacBook:
    • Go to System Settings > Network
    • Select your Ethernet adapter
    • Configure IPv4: Using DHCP with manual address
    • Set IP: 192.168.2.100 (or any 192.168.2.x address)
  3. Access Mini PC at a static IP or use mDNS discovery

⚡️ Direct Ethernet Setup Note: This method is complex and requires networking knowledge. The temporary monitor option is much simpler for initial setup.

My Approach

Use both web UI and SSH access after installation, depending on your use case. The direct Ethernet method is not recommended due to its complexity. Borrow a monitor/TV for initial installation, then use web browser or SSH for all ongoing management and access.

Troubleshooting: Boot and Display Issues

Symptom: Kernel Panic or Black Screen After Installation

If Start9 OS installs successfully but fails to boot fully or shows a black screen with no web UI access, this is often caused by GPU driver incompatibility, particularly with AMD Radeon graphics cards in Minisforum systems.

Example issue: Minisforum AI X1-255 with integrated Radeon GPU may experience kernel incompatibility with Start9 OS’s Linux kernel, preventing proper graphics initialization and system boot.

Option 1: Try Booting with Minimal Graphics Mode

If you can access the GRUB boot menu during startup:

  1. At the GRUB menu (may appear briefly), press E to edit boot parameters
  2. Find the line starting with linux and add: nomodeset
    • Example: linux /boot/vmlinuz-... root=... nomodeset
  3. Press Ctrl+X to boot with this parameter
  4. This disables GPU acceleration and may allow the system to boot
  5. If successful, access the web UI at https://xxx-yyy.local (replace with your device name) or https://192.168.1.101 (example IP address)

Result: This may allow boot to complete, but graphics performance will be degraded.

Option 2: Check for Kernel Updates

Newer Start9 OS releases may include updated kernels with better hardware support:

  1. Boot from the USB drive again
  2. Try downloading the latest stable Start9 OS release from GitHub
  3. Flash it to the USB drive (overwriting the previous installation)
  4. Retry the full installation process

Result: Sometimes newer kernels resolve hardware compatibility issues.

Option 3: Virtualized Start9 OS (used in this guide for incompatible hardware)

If Options 1-2 don’t resolve the issue, you can run Start9 OS as a virtual machine on top of a compatible Linux host OS:

Approach:

  1. Install a Linux distribution or virtualization platform with proven Radeon driver support:
    • Proxmox VE
    • Ubuntu Server 24.04 LTS
    • Debian 12
  2. Use KVM/QEMU virtualization to run Start9 OS as a guest VM
  3. Allocate sufficient resources to the VM (CPU, RAM, storage)
  4. Access Start9 OS web UI normally from the guest VM

Advantages:

  • Works around kernel incompatibilities completely
  • Flexible resource allocation
  • Can run other services on the host
  • Provides a clean separation of concerns

Disadvantages:

  • Slight performance overhead from virtualization
  • More complex initial setup
  • Requires SSH access to the host for management

For detailed instructions on this approach, see: Virtualized Start9 OS Setup Guide (Advanced)
