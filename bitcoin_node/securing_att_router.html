Securing AT&T BGW320 Router

This guide provides step-by-step instructions to secure your AT&T BGW320 router for use with Proxmox VE, Start9 OS, and Bitcoin node applications. Following these steps will help protect your infrastructure from unauthorized access and network threats.

In this guide, you will:

  • Change default admin credentials
  • Enable firewall and secure access controls
  • Configure static IP reservations (for Proxmox and Start9)
  • Disable unnecessary services (UPnP, remote management)
  • Set up port forwarding (only when needed for Bitcoin node)
  • Configure guest network isolation (optional)

Pre-requisites

Preparation

  • Ensure you have physical access to your AT&T BGW320 router and its admin label.
  • Gather admin credentials (Access Code, Wi-Fi name, Wi-Fi password).
  • Confirm you have access to a device (laptop/desktop) connected to the router’s network.

Hardware

  • AT&T BGW320 router (with admin access)
  • Minisforum X1-255 (or similar x86_64 hardware) for Proxmox VE

Software

  • Proxmox VE installed on your hardware
  • Start9 OS running (either natively or as a VM)

References

  • AT&T BGW320 Manual
  • Bitcoin Core Port Forwarding
  • Network Security Best Practices (NIST)

Step-by-Step Instructions

Step 1: Review Router Label Credentials

Your AT&T BGW320 router label contains three important credentials:

CredentialPurposeSecurity Recommendation
Access CodeRouter admin interface login✅ Keep default (random, unique per router) if physically secure
Wi-Fi NameWireless network SSID⚠️ Change (default name reveals router model and AT&T customer)
Wi-Fi PasswordWireless network password⚠️ Change (default may be shorter and less secure)

🔒 Physical Security: If your router is in a locked cabinet/room with no visitor access, the default credentials are reasonably secure. If service technicians, guests, or roommates have access, change all credentials.

Step 2: Access Router Admin Interface

  1. Open your web browser
  2. Navigate to http://192.168.1.254 (default gateway)

🌐 Admin Page Access Tip: Make sure you are connected to the local network (not cellular/mobile data). If you cannot access the admin page, try the alternate gateway address http://192.168.1.1, reset your browser cache or use incognito mode, and check your Ethernet connection to the router.

  1. The router home page loads without requiring authentication

🔑 Access Control: The AT&T BGW320 allows browsing basic status pages without authentication, but certain settings require the Access Code (from the router label) to modify. This provides reasonable security while allowing easy monitoring.

Step 3: Change Access Code

Should you change the default Access Code?

The printed Access Code on your AT&T BGW320 is randomly generated and unique to your router, making it reasonably secure if:

  • Your router is physically secured in your home
  • You trust household members and visitors won’t access the label
  • You haven’t shared the code publicly

Consider changing it if:

  • You’ve shared photos of your router online (showing the label)
  • You have concerns about physical access by service technicians or guests
  • You prefer rotating credentials as a security best practice

To change the Access Code (if already set):

  1. Go to Device → Access Code
  2. Enter current Access Code
  3. Enter a new Access Code:
    • At least 10-16 characters
    • Mix of uppercase, lowercase, numbers, and symbols
    • Use a password manager to generate and store it
  4. Click Save

🔑 Access Code Security & Recovery: Store your Access Code securely. If you lose or forget it, you must factory reset the router (hold the reset button for 10+ seconds) and reconfigure all settings from this guide. This will disconnect all devices and require you to set up your network again.

Step 4: Configure Static IP Reservations

📡 Static IPs: Ensures your Proxmox host and Start9 node always get the same IP addresses.

On the AT&T BGW320, you can only reserve IP addresses for devices within the DHCP range (192.168.1.64 to 192.168.1.253). Static IPs outside this range cannot be assigned via the web interface.

  1. Go to Device → Status
  2. Find your Proxmox host (Minisforum) and Start9 VM in the device list
  3. Note its MAC address and current IP
  4. Go to Home Network → IP Allocation
  5. Click Add or Allocate
  6. Configure Proxmox reserved IP:
    • Device Name: proxmox-minisforum
    • MAC Address: (copied from device list)
    • IP Address: 192.168.1.100 (choose from 192.168.1.64 to 192.168.1.253)
    • Click Save
  7. Repeat for Start9 VM:
    • Device Name: start9-bitcoin-node
    • MAC Address: (find VM in device list)
    • IP Address: 192.168.1.101 (choose from 192.168.1.64 to 192.168.1.253)
    • Click Save

📡 BGW320 DHCP Reservation Tips:

  • The BGW320 only allows IP reservations within the DHCP range (192.168.1.64 to 192.168.1.253). Pick an address in this range for each device you want to reserve.
  • Reserved addresses: 192.168.1.1 (router), 192.168.1.254 (gateway), 192.168.1.255 (broadcast)
  • Double-check that the device MAC address matches the reservation.
  • After reserving, reboot the device to obtain a new DHCP lease.
  • Do not assign duplicate IPs or use reserved addresses for other devices.
  • If you need a static IP outside the DHCP range, set it manually on the device and ensure it does not conflict with any reserved or DHCP-assigned addresses.

Step 5: Enable Firewall and Access Controls

🛡️ Firewall Protection: Protects your network from unauthorized access and attacks.

Based on your AT&T BGW320, verify these firewall settings:

  1. Go to Firewall tab at the top navigation
  2. Click Status to view current firewall configuration
  3. Verify the following are enabled:
    • Packet Filter: On (should already be on)
    • Firewall Advanced: On (recommended)
    • NAT Default Server: Off (unless you need DMZ - not recommended)
    • IP Passthrough: Off (unless specifically needed)

🛡️ Default Protection: For standard home and node use, also leave the following sub-menus at their default settings (usually “Off” or “Disabled”) unless you have a specific need: Packet Filter, NAT/Gaming, Public Subnet Hosts, IP Passthrough, Firewall Advanced, and Security Options. Changing these options is not recommended for most users and can reduce security.

Configure Advanced Firewall Rules (Optional)

If you need custom firewall rules:

  1. Go to Firewall → Firewall Advanced
  2. Suggested secure defaults:
    • Drop incoming ICMP Echo requests to LAN: Off (keep local ping working; turn On if you want to drop WAN-originated pings to LAN)
    • Drop incoming ICMP Echo requests to Device LAN Address: On (blocks ping to the router LAN IP from WAN/IPv6)
    • Drop incoming ICMP Echo requests to Device WAN Address: On (blocks ping to the router WAN IP)
    • Reflexive ACL: On (stateful inspection; keep enabled)
    • ESP ALG: Off (enable only if you run IPsec passthrough)
    • SIP ALG: On (default; generally safe, but if VoIP issues arise, try turning this Off)

Step 6: Change Wi-Fi Network Name and Password

📶 Wi-Fi Security: Default Wi-Fi credentials reveal your router model and may be less secure.

  1. Go to Home Network → Wi-Fi (or 2.4 GHz Settings / 5 GHz Settings)
  2. Change the Network Name (SSID):
    • Choose a unique name that doesn’t reveal personal information
    • Avoid using your name, address, or “ATT” in the SSID
    • Example: HomeNetwork2025 instead of ATT-Wi-Fi-ABCD
  3. Change the Wi-Fi Password:
    • Create a strong passphrase (20+ characters recommended)
    • Mix of uppercase, lowercase, numbers, and symbols
    • Use a password manager to generate and store it
    • Example: Correct-Horse-Battery-Staple-2025!
  4. Verify Security settings:
    • Security: WPA (default)
    • WPA Version: WPA-2 (default; sufficient security for most users)

🔐 Wi-Fi Encryption: WPA-3 may not be available on BGW320. WPA-2 is secure when using a strong password (20+ characters)

  1. SSID Broadcast: Keep enabled (disabling doesn’t significantly improve security)
  2. Click Save
  3. Repeat for both 2.4 GHz and 5 GHz networks if configured separately

🔄 Reconnect Devices: After changing Wi-Fi credentials, you’ll need to reconnect all devices (phones, laptops, smart home devices) with the new password.

Step 7: Set Up Guest Network

🧑‍💻 Guest Network: Isolates untrusted devices from your Bitcoin infrastructure.

  1. Go to Home Network → Wi-Fi → Guest Network
  2. Enable guest network
  3. Configure:
    • SSID: ATT-Guest (or custom name)
    • Network Access: Internet Only (isolates guests from your home LAN)
    • Security: WPA with WPA Version: WPA-2
    • Password: Strong unique password
  4. Click Save

📱 Guest Use Case: Connect phones, IoT devices, or visitor devices to guest network.

Step 8: Review Connected Devices Regularly

🕵️‍♂️ Device Monitoring: Detects unauthorized devices on your network.

  1. Go to Device → Status
  2. Review all connected devices
  3. Verify each device is recognized:
    • Proxmox host (Minisforum)
    • Start9 VM (e.g., xxx-yyy)
    • Your laptop/MacBook
    • Any other authorized devices
  4. If unknown device found:
    • Note its MAC address
    • Go to Firewall → MAC Filtering
    • Add to block list

Step 9: Firmware Updates

🔄 Auto Firmware Updates: The AT&T BGW320 firmware updates are managed automatically by AT&T. There is no user-accessible menu in the web interface to manually configure or trigger firmware updates. AT&T pushes updates to the gateway automatically when new firmware is available.

Keeps router secure with latest security patches. You can verify your current firmware version:

  1. Go to Device → System Information
  2. Look for Software Version in the device information

The router will automatically download and install firmware updates from AT&T. No manual configuration is required.
