Installing Mempool Explorer

Mempool Explorer lets you visualize Bitcoin transactions, blocks, and mempool activity in real time. It is the perfect companion to your Bitcoin Core node on Start9 OS.

In this guide, you will:

  • Access the Start9 Marketplace
  • Install Mempool Explorer
  • Configure backend connection
  • Access the Mempool web interface

Pre-requisites

Preparation

  • Bitcoin Core installed and fully synchronized
  • Start9 OS running and accessible via web interface
  • Master password set during initial setup

Hardware

  • Start9 OS device (native or Proxmox VM)
  • MacBook or desktop for access

Software

  • Web browser (Safari, Chrome, Firefox, etc.)

References

  • Mempool Documentation

Step-by-Step Instructions

Step 1: Access Start9 Marketplace

Mempool Explorer is available in the Start9 Marketplace. To begin:

  1. Open your web browser
  2. Navigate to your Start9 web interface:
    • Local access: https://xxx-yyy.local (replace with your device name)
    • IP access: https://192.168.1.101 (use your Start9 IP address)
  3. Log in with your Start9 master password

🌐 Marketplace Help: If you don’t see Mempool Explorer, ensure you’re connected to the internet and refresh the marketplace.

Step 2: Install Mempool Explorer

  1. Click on Marketplace in the left sidebar
  2. Search for “Mempool” in the search bar
  3. Locate Mempool Explorer in the results
  4. Click on Mempool Explorer to open the service details
  5. Review the service description and requirements
  6. Click Install button
  7. Wait for the download and installation to complete (~2-5 minutes)

Step 3: Configure Mempool Explorer

After installation completes:

  1. Go to Services in the sidebar
  2. Click on Mempool Explorer
  3. Click the Configure button (or Menu → Config) to configure the service (see below).
  1. Ensure your Bitcoin Core node is selected as the backend in the dependencies section.

🔗 Backend Connection:

  • Mempool Explorer requires a running Bitcoin Core node. If Bitcoin Core is not detected, make sure it is installed, fully synced, and running.
  • If you have multiple Bitcoin nodes, select the correct one in the backend dropdown.
  1. Review the highlighted Bitcoin Core configuration requirements for Mempool Explorer:
    • Pruning: Pruning must be fully disabled (not “Automatic”). Transaction Index (txindex) cannot be enabled unless pruning is off.
    • Transaction Index (txindex): Must be enabled (On) so Mempool Explorer can access the full transaction database. This option will only be available if pruning is disabled.
    • ZeroMQ: Must be enabled (On) to allow real-time updates from Bitcoin Core to Mempool Explorer.

🗄️ Pruning & Transaction Index:

  • You cannot enable Transaction Index (txindex) unless pruning is fully disabled. If your Start9 interface only shows “Automatic” for pruning, you will not be able to use Mempool Explorer until you can set pruning to “Disabled” (no pruning).
  • Start9 automatically checks whether you have enough storage for the full Bitcoin blockchain; if space is insufficient, the “Disabled” option will not appear. Free up space or add storage, then reopen the settings to see the disabled/no-pruning option.
  • If you cannot disable pruning, Mempool Explorer will not function correctly.

Step 4: Access Mempool Web Interface

  1. In the Services list, click Mempool Explorer
  2. If the service shows Stopped, click Start and wait for it to reach Running
  3. Click the provided link to open the Mempool web interface
  4. Explore mempool transactions, blocks, and fee estimates

Troubleshooting

Mempool web UI does not open after clicking Launch UI — URL is https://xxx-yyy.local:

Start9 serves service web UIs at a .local mDNS hostname (e.g., https://abc123-xyz456.local), not at the IP address you use to reach the admin panel. The browser has to resolve that hostname separately via mDNS (Bonjour) and trust the Start9 Root CA certificate for it. Two things can go wrong:

Step 1 — Check whether your MacBook can resolve the .local hostname:

ping -c 3 abc123-xyz456.local
  • Ping succeeds → mDNS is working; the problem is the certificate (go to Step 2)
  • Ping fails → mDNS is not working (Start9 likely does not run avahi-daemon); use the static hosts entry fix below

Fix for ping failure — add a static hosts entry on your MacBook:

echo "192.168.1.101 abc123-xyz456.local" | sudo tee -a /etc/hosts

Replace abc123-xyz456.local with your actual Start9 hostname (visible in the URL when Launch UI opens a tab). Then verify:

grep abc123 /etc/hosts
ping -c 3 abc123-xyz456.local

Ping should now resolve to 192.168.1.101. macOS checks /etc/hosts before mDNS for .local names, so this bypasses mDNS entirely. This is the recommended long-term fix — it is static, survives reboots, and does not depend on Start9’s mDNS configuration.

If you access Start9 from another device (a second Mac, etc.), add the same hosts entry on that device too.

Step 2 — Install the Start9 Root CA on your MacBook:

The Start9 Root CA is the certificate authority that signs all .local HTTPS certificates for your node. Without it, the browser will refuse to load any https://xxx-yyy.local address (including service UIs).

Follow the Root CA installation steps in Securing Start9 OS — Step 3, Option 1. After installing and trusting it in Keychain, restart your browser — the Mempool UI at https://abc123-xyz456.local will load without warnings.

Why accessing via IP works but .local does not: The certificate issued for abc123-xyz456.local does not cover 192.168.1.101. The browser treats them as completely different identities. Installing the Root CA resolves this for all .local addresses in one step — you will not need to accept certificate warnings again for any Start9 service.

Mempool shows “loading” or stale data:

  • Confirm Bitcoin Core is fully synced (100%) in the Start9 Services list
  • Confirm Bitcoin Core has txindex enabled and pruning disabled (required — see Step 3)
  • Confirm Bitcoin Core has ZeroMQ enabled (required for real-time updates)
  • Restart Mempool Explorer: Services → Mempool Explorer → Stop → Start

Mempool service shows “Needs Config” or dependency error:

  • Go to Services → Mempool Explorer → Configure and confirm Bitcoin Core is selected as the backend
  • If Bitcoin Core’s txindex or ZeroMQ settings changed, re-save its configuration and restart Bitcoin Core first, then restart Mempool

Mempool service stays in “Starting” state:

  • Bitcoin Core must be fully synced before Mempool can initialize. Wait for Bitcoin Core to reach 100% sync.

Service log shows “Could not connect to https://api.bitfinex.com/v1/pubticker/BTCJPY”:

  • This is non-critical log noise. Mempool fetches live Bitcoin price data from several external APIs for currency conversion display. Bitfinex’s v1 API (/v1/pubticker/) is deprecated and unreliable — it is frequently rate-limited, geo-blocked, or simply unavailable.
  • The core Mempool functionality — block explorer, transaction lookup, mempool fee estimates, and real-time visualization — is completely unaffected. Only the BTC/JPY price display may be missing or stale.
  • No action is required. The outbound firewall Rule 11 (TCP 443) already permits this connection — the failure originates from Bitfinex’s servers, not your firewall.
