Setting up Hardware with AT&T BGW320 (Fiber 1 GIG)

This section explains how to connect the chosen equipment to the AT&T BGW320 router, which provides a 1 GIG fiber internet package. The goal is to ensure stable, high‑speed connectivity for running a Bitcoin node with Start9 OS.

Pre-requisites

Before starting, ensure you are ready with all required hardware, software, and preparations as outlined below and in the previous step.

Preparations

  • Prepare your workspace with all components and tools

Hardware

  • MINISFORUM X1-255 Mini PC (with RAM and SSD installed; OcuLink chip will be installed in a later step)
  • SanDisk 64GB USB drive (for flashing Proxmox VE ISO image)
  • UGREEN Cat 8 Ethernet cable (3FT or longer)
  • AT&T BGW320 router (with available LAN ports)
  • Monitor and keyboard (for initial BIOS setup and configuration)
  • MacBook Air M1 (as a laptop client for remote access to Minisforum)
  • Power outlets for Mini PC and router

🔄 USB Drive Usage Notice: The SanDisk USB drive was originally planned for Start9 OS installation, but is now used to hold the Proxmox VE ISO due to incompatibility between Start9 and the MINISFORUM X1-255 hardware. Start9 runs as a VM inside Proxmox. See → Start9 Compatibility Notes for details.

Software

  • Proxmox VE ISO (latest stable release)
  • Start9 OS image (latest stable release)
  • Balena Etcher (for flashing USB drives)
  • Web browser (Safari, Chrome, Firefox, etc.)
  • SSH client (optional, for advanced troubleshooting)

References

  • Proxmox VE Official Downloads
  • Start9 Documentation
  • Balena Etcher
  • AT&T BGW320 Manual
  • Bitcoin Core Documentation
  • Start9 Community Forums

Step‑by‑Step Setup

🗂️ Hardware Setup Steps: The following step sequence and time estimates are based on my own hardware setup experience. Your process may vary depending on hardware, network, and prior experience.

Step 1: Prepare the Start9 Boot Drive

Create a bootable USB drive with the Start9 OS image.

📖 → Detailed Guide: Flashing Start9 OS to USB Drive

What you’ll accomplish:

  • Download Start9 OS (stable release)
  • Install Balena Etcher on MacBook Air M1
  • Flash the image to your SanDisk USB drive
  • Safely eject and prepare for installation

Time required: ~15 minutes

Step 2: Inspect Minisforum Hardware

Verify the internal components and install the OcuLink chip.

📖 → Detailed Guide: Inspecting Minisforum Hardware

What you’ll accomplish:

  • Open the Minisforum case safely
  • Verify 32GB DDR5 RAM installation
  • Confirm 1TB NVMe SSD presence
  • Install OcuLink chip/port
  • Close and secure the case

Time required: ~20 minutes

Step 3: Connect to Network

Connect the Mini PC to your AT&T BGW320 router via Ethernet.

📖 → Detailed Guide: Connecting Mini PC to Router

What you’ll accomplish:

  • Position hardware optimally
  • Identify correct Ethernet ports
  • Connect Cat 8 cable
  • Verify connection LEDs
  • Connect power supply

Time required: ~10 minutes

Step 4: Boot and Install Start9 OS

Boot from USB and install Start9 OS on the internal SSD.

📖 → Detailed Guide: Booting into Start9 OS

What you’ll accomplish:

  • Connect monitor and keyboard
  • Access BIOS/boot menu
  • Select USB boot device
  • Install Start9 OS to SSD
  • Complete first boot setup

Time required: ~30 minutes (direct install)

⚙️ Hardware Compatibility Notice: If Start9 OS fails to boot directly on the Minisforum X1-255 (kernel panics, black screens, GPU incompatibility), see → Start9 Compatibility Notes below for the recommended virtualized setup approach using Proxmox VE.

📖 → Alternative: Virtualized Start9 OS Setup (Proxmox VE)

What you’ll accomplish:

  • Install Proxmox VE on Minisforum X1-255 hardware
  • Configure Proxmox VE for secure virtualization
  • Create and configure a Start9 OS virtual machine (VM)
  • Install Start9 OS inside the VM
  • Set up network connectivity for the VM
  • Access Start9 web UI from your MacBook via https://xxx-yyy.local (replace with your device name; see below) or https://192.168.1.101 (example IP)
  • Troubleshoot hardware compatibility and virtualization issues

Time required: ~90 minutes (Proxmox install + VM setup + Start9 install)

Step 5: Configure Network Settings

Configure the network connection in Start9 OS to enable internet access and confirm your node has full gigabit connectivity for optimal blockchain synchronization.

📖 → Detailed Guide: Configuring Network Settings and Speed Verification

What you’ll accomplish:

  • Access Start9 OS setup wizard
  • Select wired Ethernet connection
  • Verify DHCP IP address assignment
  • Confirm gigabit connection speed (1 Gbps)
  • Run speed tests from multiple sources
  • Verify router connection details
  • Troubleshoot any speed issues
  • Complete initial network configuration

Time required: ~10 minutes

Step 6: Secure Proxmox VE (if using Proxmox virtualization)

If you chose the virtualized setup (Proxmox VE) rather than installing Start9 directly on the hardware, secure the Proxmox host before provisioning the Start9 VM.

📖 → Secure Proxmox VE

What you’ll accomplish:

  • Ensure the Proxmox host is patched and up to date
  • Configure SSH key access and disable password login for root
  • Set up the host firewall and management access rules

Time required: ~20 minutes

Step 7: Secure AT&T BGW320 Router

Before exposing services on your network, secure the AT&T BGW320 router (admin credentials, remote management, firewall/port-forwarding rules).

📖 → Secure AT&T BGW320 Router

What you’ll accomplish:

  • Change default admin password and create a local admin account if applicable
  • Disable remote/portal access from the WAN side
  • Configure any required port-forwards carefully and document them

Time required: ~15 minutes

Estimated Total Time:

  • Direct Start9 install: ~1 hour 30 minutes
  • Proxmox VM route: ~2 hours 50 minutes

Start9 Compatibility Notes

Why Proxmox VE instead of Direct Start9?

The MINISFORUM X1-255 is not fully compatible with Start9 OS as of early 2025. While the hardware is powerful enough to run Start9, installation and driver support are problematic. The solution is to:

  1. Install Proxmox VE on the MINISFORUM hardware as the hypervisor
  2. Run Start9 as a VM within Proxmox, providing excellent isolation and resource management
  3. Maintain full Bitcoin sovereignty while ensuring hardware stability

This approach actually provides advantages:

  • Better resource isolation between Proxmox host and Start9 VMs
  • Ability to run multiple VMs if needed (backups, testing, etc.)
  • More reliable hardware driver support via Linux kernel
  • Cleaner separation of concerns

For more information on the Phase 1 and Phase 2 storage architecture supporting this setup, see → Future Expansion Plan in Choosing Equipment.
