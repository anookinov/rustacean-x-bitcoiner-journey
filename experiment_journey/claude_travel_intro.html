Rustacean X Bitcoiner Journey

Claude Desktop: AI Travel Planning Partner

Planning a multi-leg trip is research-heavy work — comparing cruise schedules, checking hotel pricing across seasons, reading weather forecasts by port, and tailoring everything to whoever is actually traveling. Most people do this manually: switching between browser tabs, copy-pasting prices into a spreadsheet, and starting over when the traveler changes. Claude Desktop collapses all of that into a single conversation.

This guide walks through one concrete end-to-end workflow: reading an existing trip captured in a Google Sheet, adapting it to a new traveler with a different profile, and generating a ready-to-use itinerary in a new Google Sheet. The baseline trip is a 14-day Vancouver-to-Alaska journey including a 7-day Discovery Princess cruise. The goal is to use everything that previous planner already figured out — logistics, costs, what booked out early, what was worth the money — and build a new plan that fits someone different.

In this guide, you will:

  • Install Claude Desktop and configure a Travel Planning Project
  • Import a past trip’s Google Sheet data and run a structured analysis
  • Profile a new traveler with different constraints, budget, and preferences
  • Ask Claude to research current cruise schedules, pricing, weather, and availability
  • Generate a customized 14-day itinerary and export it to a new Google Sheet

Setup

Step 1: Install Claude Desktop

Download the macOS app from claude.ai/download and sign in with your Anthropic account. The browser version at claude.ai works identically — use either.

Claude Pro ($20/month) is required for this workflow. It adds file upload support, longer context (needed to paste full itinerary data), and web search access for real-time pricing research.

Step 2: Create a Travel Planning Project

Claude Projects persist a custom instruction set across all conversations inside the project. Set one up so Claude knows your role and output preferences without re-explaining them every session.

  1. Open Claude Desktop

  2. Click New Project in the left sidebar

  3. Name it Travel Planning — Vancouver/Alaska Baseline

  4. In the Project Instructions field, describe your context:

    About me: [Your role — "planning a trip for my parents", "travel agent
comparing itinerary options", "solo traveler adapting a past cruise trip"]

Planning preferences:
- Budget style: [budget / mid-range / luxury]
- Pace preference: [slow and relaxed / active and packed / mix]
- Priorities: [wildlife / history / food / adventure / comfort]

Output format:
- Prefer tables for day-by-day itineraries
- Include cost estimates in CAD and USD where relevant
- Flag any recommendations where information may be outdated

  5. Save the Project — every travel planning conversation you start inside it inherits this context

💡 One Project per context: If you are planning trips for multiple people with different profiles, create a separate Project for each. “Planning for my mother (68, limited mobility, comfort-focused)” gives Claude more useful defaults than “I plan trips for various people.”

Step 3: The Core Technique — Context-Goal-Format

Every effective Claude prompt has three parts:

Context:  What you have (past trip data, traveler profile, constraints)
Goal:     What you want Claude to produce (analysis, itinerary, research summary)
Format:   How to structure the output (table, bullet list, CSV for Google Sheets)

Prompts that skip Context produce generic outputs. Prompts that skip Format produce walls of text. The prompts throughout this guide embed all three — notice the pattern as you adapt them to your situation.

The Travel Planning Workflow

This guide is split into three parts. Complete them in order — each part builds on the output of the previous one.

Part 1: Reading the Past Travel Plan

→ Part 1: Reading the Past Travel Plan

You export the existing Google Sheet, paste it into Claude, and ask Claude to extract the key logistics, cost structure, booking lessons, and what worked. This becomes the research foundation — Claude now “knows” the past trip in detail and can reference it throughout the planning process.

Part 2: Profiling the New Traveler & Researching Current Conditions

→ Part 2: Profiling the New Traveler & Researching Current Conditions

You describe the new traveler’s profile — age, mobility, budget, interests, travel dates — and ask Claude to research how current conditions differ from the baseline trip. Claude identifies what Princess Cruises itineraries are available in the new travel window, how August pricing compares to June, what weather changes by port, and which excursions need different handling for this traveler’s physical profile.

Part 3: Building the New Trip Plan & Creating the Google Sheet

→ Part 3: Building the New Trip Plan & Creating the Google Sheet

You ask Claude to synthesize the baseline analysis, traveler profile, and research into a complete customized itinerary. Claude generates four tabs of output in CSV format — daily itinerary, cruise excursions, accommodation, and budget estimate — formatted for direct paste into a new Google Sheet. You copy, paste, and have a complete travel document in minutes.
